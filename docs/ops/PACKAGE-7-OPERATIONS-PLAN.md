# الحزمة 7: خطة الإعداد التشغيلي (تخطيط فقط)

> **الحالة:** خطة للموافقة.
> - **لم يُنشأ أي حساب أو خدمة، ولم يُنشر شيء**، ولا يُستقبل مستخدمون حقيقيون (قرار المالكة 8 بعد مراجعة الحزمة 5).
> - هذه الخطة **تُرتّب** قائمة الجاهزية القائمة `docs/pilot/LIVE-ENVIRONMENT-CHECKLIST.md`، الأقسام A–H، ولا تكرّرها.
> - الأسعار تُتحقق منها مباشرة **وقت طلب الموافقة** على كل خدمة، لا قبله (قرار المالكة 9 في المرحلة ب). لذلك لا أسعار هنا.

## 4. حساب GitHub للمراجِع: الصلاحيات والمخاطر (مؤجّل حسب قرار المالكة 6)

**الحاجة:** في نشاط «طلبات الإجازة» يسلّم الخرّيج رابط طلب دمج من مستودع **خاص** (قرار المالكة 5). يحتاج المراجِع البشري قراءته.

| البند | ما يلزم | المخاطر | التخفيف المقترح |
|---|---|---|---|
| نوع الحساب | حساب GitHub لمؤسسة نَقْلة، لا حساب شخصي لمراجِع | ضياع الوصول إن غادر المراجِع | حساب مؤسسي بمصادقة ثنائية وكلمة سر في خزنة |
| الصلاحية على مستودع الخرّيج | دعوة الخرّيج للحساب كمتعاون. **مستوى الصلاحية في المستودعات الشخصية قيد التحقق من وثائق GitHub الرسمية** | إن كانت الدعوة تمنح كتابة، يستطيع الحساب الدفع إلى مستودع الخرّيج | سياسة «قراءة فقط» مكتوبة؛ عدم استخدام الحساب للكتابة؛ مراجعة سجل نشاطه |
| مدة الوصول | من التسليم حتى انتهاء المراجعة | وصول دائم غير ضروري | تعليمات للخرّيج بإزالة الحساب بعد صدور النتيجة؛ قائمة دورية للمستودعات المفتوحة |
| البيانات | المنصة لا تنسخ المستودع ولا تشغّل كوده | تسرّب كود الخرّيج إن اختُرق الحساب | مصادقة ثنائية؛ لا رموز وصول دائمة؛ لا تطبيقات طرف ثالث على الحساب |
| البديل | مستودعات داخل منظمة GitHub لنَقْلة، بدور «قراءة» على مستوى المنظمة | تغيير نموذج ملكية عمل الخرّيج | يُدرس فقط إن ثبت أن صلاحية المتعاون كتابة |

**لا يُنشأ الحساب قبل موافقتك على هذا الجدول.**
