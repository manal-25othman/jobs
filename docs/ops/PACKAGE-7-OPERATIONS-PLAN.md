## 4. حساب GitHub للمراجِع: الصلاحيات والمخاطر (مؤجّل حسب قرار المالكة 6؛ متحقَّق منه الآن)

**التحقق:** فُتحت 5 صفحات رسمية من docs.github.com مباشرة. التقرير: `docs/ops/research/GITHUB-REVIEWER-PERMISSIONS-CHECK.md`.

| الحقيقة الموثَّقة | الأثر |
|---|---|
| في مستودع **حساب شخصي**: «لا يمكن للمتعاونين الحصول على صلاحية قراءة فقط»؛ المتعاون يستطيع الدفع ودمج طلبات الدمج | **دعوة حساب المراجِع إلى مستودع شخصي تمنحه كتابة**، وهذا يخالف هدف «قراءة مؤقتة فقط» في القرار 5 |
| في مستودع **منظمة**: دور Read يتيح القراءة وتقديم مراجعة على طلب الدمج، ولا يتيح الدفع ولا الدمج ولا تغيير الإعدادات؛ ويمكن منحه لمتعاون خارجي | الطريق الوحيد لقراءة فقط |
| الإزالة يدوية؛ لا انتهاء تلقائي موثَّق؛ تبقى النسخ المحلية لدى من أُزيل | يلزم إجراء إزالة بعد المراجعة، وسياسة لعدم الاحتفاظ بنسخ |
| المتعاون الخارجي على مستودع خاص في منظمة **مدفوعة** يستهلك رخصة؛ وفي الخطة المجانية لا | تكلفة محتملة حسب خطة منظمة الخرّيج |

**الخيارات:**

| الخيار | الوصف | الإيجابيات | السلبيات |
|---|---|---|---|
| **أ. (موصى به)** منظمة GitHub مجانية **يملكها الخرّيج** لمستودع النشاط | الخرّيج ينشئ منظمة مجانية ومستودعًا خاصًا فيها، ويضيف حساب المراجِع **متعاونًا خارجيًا بدور Read** | قراءة فقط فعلًا؛ الملكية تبقى للخرّيج؛ لا تكلفة في الخطة المجانية | خطوات إضافية للخرّيج تحتاج دليلًا واضحًا |
| ب. مستودع شخصي ومتعاون بصلاحية كتابة | الأبسط للخرّيج | صلاحية كتابة لا لزوم لها، وخطر تعديل عمل الخرّيج | غير موصى به |
| ج. مستودعات داخل منظمة نَقْلة | تحكم كامل للمنصة | تغيّر ملكية العمل، وتحتاج قرارًا | لاحقًا فقط إن لزم |

**لا يُنشأ أي حساب ولا تُمنح أي صلاحية قبل موافقتك.** إن اعتمدتِ (أ) فالتغيير في دليل النشاط فقط (README مواد البداية)، والمتطلب نفسه (رابط طلب الدمج ورمز الإيداع) لا يتغيّر.

## 4.1 حالة S0 (ملفات فقط، بموافقتك)
- `ops/docker/api.Dockerfile` و`ops/docker/app.Dockerfile` و`.dockerignore`: صور غير جذرية، بلا أسرار. **لم تُبنَ في هذه البيئة** لعدم توفر خدمة Docker؛ تُختبر في S1.
- `ops/ci/ci.yml.proposed`: سير عمل CI **غير مفعَّل** عمدًا، خارج `.github/workflows`. تفعيله يشغّل GitHub Actions ويحتاج موافقتك.
- **CORS (P0-3) أُغلق في الإنتاج:** `CORS_ALLOWED_ORIGINS` إلزامي فيه ويرفض «*»، ويبقى مفتوحًا للتطوير فقط. مع اختبارات.
