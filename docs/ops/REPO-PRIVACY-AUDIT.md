## 2. فحص الأسرار في التاريخ الكامل (104 إيداعات، كل الفروع المجلوبة)

- **أنماط مفاتيح حقيقية:** لا شيء. فُحصت مفاتيح AWS وAnthropic وOpenAI، ورموز GitHub بأنواعها، وSlack، والمفاتيح الخاصة PEM، ورموز JWT، وروابط Postgres بكلمات مرور لـSupabase.
- **ملفات حساسة الاسم:** `.env.example` فقط، وقيمه نماذج مثل `local-jwt-secret-change-me` و`local-service-role-key`، وهي ليست أسرارًا.
- **أسرار الاختبار** (`test-jwt-secret-for-e2e-only-not-a-real-key`، وأسرار webhook في الاختبارات): مكتوبة صراحةً للاختبار، ولا تُستخدم في أي بيئة.
- **التوصية:** بعد التحويل، فعّلي **Secret scanning** و**Push protection** من إعدادات الأمان إن كانت متاحة لخطتك. التحقق من توفرها للمستودعات الخاصة في الخطة المجانية جارٍ في جلسة البحث.

| **الروابط القديمة** | تصبح غير متاحة لغير المصرّح لهم |

## 6. الخطوات المباشرة (منكِ)

1. افتحي `https://github.com/manal-25othman/jobs` → **Settings**.
2. في **General** انزلي إلى **Danger Zone** → **Change repository visibility** → **Change to private**.
3. أكّدي باسم المستودع كما يطلب GitHub.
4. في **Settings → Code security** فعّلي ما يتاح لخطتك: Secret scanning وPush protection وDependabot alerts.
5. أخبريني بعد التحويل لأتحقق من الرؤية، وأن CI يعمل في المستودع الخاص.
