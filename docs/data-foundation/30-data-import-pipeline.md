# الوثيقة 24 — Data Import Pipeline
> خط استيراد وتطبيع ومطابقة ومراجعة. **تصميم فقط — لا استيراد فعلي ولا أداة ولا كود.**

## 1. الخط الكامل

```
Source → Import → Normalize → Deduplicate → Map → Review → Publish
 (L0)     (L0)      (L1)        (L1/L2)      (L2)   (L2)     (L3)
```

| المرحلة | المخرَج | آلي/بشري | يوقف الخط؟ |
|---|---|---|---|
| **Source** | سجل في `SOURCES.json` + ترخيص واضح | بشري (قرار اعتماد المصدر) | **نعم** — مصدر بلا ترخيص يُرفض |
| **Import** | لقطة L0 غير قابلة للتعديل + بيانات الالتقاط | آلي | نعم عند فشل الالتقاط |
| **Normalize** | سجلات L1 موحّدة الشكل | **آلي بالكامل** | لا |
| **Deduplicate** | مرشّحات تكرار **مقترحة** | آلي يقترح · **بشري يقرر** | لا |
| **Map** | ربط بالمعرّفات الداخلية | **بشري يقرر** | نعم عند تعذّر المطابقة |
| **Review** | `sme_reviewed` → `approved` | **بشري (SME)** | **نعم** — حاجب |
| **Publish** | حزمة L3 مُصدَّرة + manifest | بشري يبدأ · آلي ينفّذ | نعم عند فشل بوابات الجودة |

---

## 2. Import — الالتقاط

**القواعد:**
1. **لقطة كاملة لا مقتطف.** نحفظ المصدر كما هو، لا ما نظن أننا نحتاجه.
2. **بيانات التقاط إلزامية:** `source_id` · `retrieved_at` · `version` · طريقة الالتقاط · بصمة المحتوى.
3. **لا تعديل ولا ترجمة ولا حذف في L0** — ولو كان المحتوى مشوّشًا.
4. **إعادة الالتقاط لا تستبدل** — لقطة جديدة بإصدار جديد، والقديمة تبقى.
5. **مصدر بترخيص مقيّد:** يُسجَّل في `SOURCES.json` بقيوده، **ولا يُستخرج منه ما يخالف الترخيص** — وهذا قرار بشري لا آلي.

---

## 3. Normalize — التطبيع *(آلي بالكامل، بلا قرار دلالي)*

| العملية | التفصيل |
|---|---|
| توحيد الترميز | UTF-8 · تطبيع Unicode |
| تنظيف نصي | مسافات زائدة · محارف تحكم · فواصل أسطر |
| **تطبيع عربي** | توحيد الألف (`أ إ آ` ← `ا` **في مفتاح المطابقة فقط**) · توحيد `ى/ي` و`ة/ه` · حذف التشكيل والتطويل — **كل ذلك في مفتاح المطابقة، مع الحفاظ على النص الأصلي كما كُتب** |
| تطبيع إنجليزي | حالة الأحرف في المفتاح · إزالة الترقيم الطرفي |
| اكتشاف اللغة | وسم كل نص بلغته |
| توحيد الوحدات والتواريخ | ISO للتواريخ · دقائق للمدد |
| **فصل المهارات المركّبة** | «SQL و Power BI» ← مرشّحان مستقلان · «تحليل البيانات وإعداد التقارير» ← مرشّحان — **مرشّحات لا قرارات** |
| توحيد الاختصارات | `BI` ↔ `Business Intelligence` **كمرشّح مترادف** لا كدمج |

> **قاعدة الفصل الحاسمة:** كل ما في L1 **قابل لإعادة التوليد آليًا من L0**. أي خطوة تحتاج حكمًا بشريًا **ليست تطبيعًا** — مكانها L2.

---

## 4. كيف نتعامل مع اختلاف أسماء المهارات

**المشكلة الواقعية:** المهارة الواحدة تظهر بصيغ عديدة:
`SQL` · `استعلامات SQL` · `قواعد البيانات - SQL` · `Structured Query Language` · `كتابة استعلامات`
`Power BI` · `PowerBI` · `MS Power BI` · `بور بي آي` · `تصميم لوحات معلومات`

### الحل: معرّف كانوني + سجل مترادفات صريح

| الطبقة | الدور |
|---|---|
| `skill_id` | **الهوية الدائمة** — لا يتغير ولا يُشتق من اسم |
| `name_ar` · `name_en` | **الاسم الكانوني المعروض** — قابل للتغيير بحرية |
| `SKILL_SYNONYMS.json` | **كل الصيغ الأخرى** بمصدرها ونوع تطابقها |

### `SKILL_SYNONYMS.json`
| الحقل | ملاحظات |
|---|---|
| `synonym_id` | — |
| `skill_id` | المهارة الكانونية |
| `surface_form` | الصيغة كما ظهرت |
| `language` | `ar` · `en` |
| `form_type` | `exact` · `abbreviation` · `transliteration` · `vendor_variant` · `descriptive_phrase` |
| `match_type` | **`equivalent` · `broader` · `narrower` · `related`** |
| `source_id` | من أين جاءت |
| `decided_by` · `decided_at` | **قرار بشري موثّق** |
| `confidence` | — |

**قواعد ملزمة:**
1. **`broader` و`narrower` لا تُدمج — تُربَط.** «تحليل البيانات» أوسع من «SQL»؛ دمجهما يفسد التشخيص.
2. **الترجمة ليست مترادفًا تلقائيًا.** «تصميم لوحات معلومات» قد تعني Power BI أو Tableau أو مفهومًا عامًا — القرار بشري.
3. **اسم المنتج التجاري (`tool`) لا يُدمج في المفهوم (`core`).** «Power BI» مهارة أداة · «تصور البيانات» مهارة مفهوم · بينهما علاقة `related` لا `equivalent`.
4. **كل مترادف قرار موثّق** بمن قرّره ومتى — لأن خطأ المترادف يظهر كخطأ تشخيص لاحقًا، ويصعب تتبّعه.

## 5. Deduplicate — منع التكرار

### الآلية (اقتراح آلي + قرار بشري)
```
1. مفتاح تجميع (blocking)  ← تطبيع + عائلة المهارة + اللغة
2. مقارنة تشابه            ← على المفتاح المطبَّع + تطابق المترادفات المعروفة
3. تصنيف المرشّح            ← duplicate / synonym / broader / narrower / distinct
4. قرار بشري               ← دمج · ربط · إبقاء منفصلًا · رفض
5. تسجيل القرار            ← في SKILL_SYNONYMS أو حالة merged_into
```

### قواعد صارمة
| القاعدة | السبب |
|---|---|
| **لا دمج آلي للمهارات مهما ارتفع التشابه** | المهارة كيان هوية · الدمج الخاطئ يُفسد أدلة مرتبطة بها |
| الدمج = `status: merged_into` + `merged_into_id` **بلا حذف** | الأدلة القديمة تشير إلى المعرّف الأصلي ويجب أن تُحلّ |
| **لا إعادة استخدام معرّف محذوف** أبدًا | يمنع خلط أدلة تاريخية |
| التكرار في **الموارد التعليمية** يُدمج آليًا بمطابقة الرابط | مخاطرة منخفضة |
| التكرار في **المهام والأنشطة** قرار تحريري | التشابه فيها مقصود أحيانًا |

### الأخطر: التكرار الخفي
مهارتان بمعرّفين مختلفين تعنيان الشيء نفسه ← **تنقسم أدلة المستخدم بينهما فلا تبلغ أيٌّ منهما `Verified`**.
**الوقاية:** تقرير تغطية دوري يرصد مهارات متقاربة بلا علاقة مسجّلة بينها *(اقتراح آلي · قرار بشري)*.

## 6. Map — المطابقة بالمعرّفات الداخلية

| الحالة | الإجراء |
|---|---|
| مطابقة تامة لمترادف معروف | ربط آلي مقبول |
| مطابقة جزئية | مرشّح للمراجعة البشرية |
| **مفهوم جديد فعلًا** | **إنشاء `skill_id` جديد في السجل العالمي أولًا** ثم الربط |
| صيغة غامضة | تبقى `unmapped` وتظهر في تقرير المراجعة — **لا تُخمَّن** |
| مفهوم خارج نطاق المسارات | يُسجَّل ويُرفض بسبب |

**قاعدة إنشاء معرّف جديد:** المهارة الجديدة تحتاج: تعريفًا يفصلها عن أقرب مهارة · مؤشرات ملاحَظة · عائلة · نوعًا · مقياس إتقان · سياسة حداثة · و**سببًا مكتوبًا لعدم كفاية مهارة قائمة**. بلا ذلك **يُرفض الإنشاء** — وإلا تضخّم السجل بمهارات مترادفة.

---

## 7. العربية والإنجليزية

| القاعدة | التفصيل |
|---|---|
| **الاسمان إلزاميان** | `name_ar` و`name_en` لكل مهارة ومهارة ومهمة ودور |
| **المعرّفات ASCII دائمًا** | `snake_case` إنجليزي · **لا معرّف عربي** — يمنع مشاكل الاتجاه والترميز والمقارنة |
| **الاسم الكانوني العربي قرار SME** | ليس ترجمة حرفية — بل **المصطلح المستخدم فعلًا في سوق العمل السعودي** |
| **المصطلحات التقنية تبقى إنجليزية داخل النص العربي** | `SQL` · `Power BI` · `React` — لا تُعرَّب قسرًا |
| **النقحرة تُسجَّل كمترادف** | «بور بي آي» `form_type: transliteration` |
| **تطبيع عربي في المفتاح فقط** | النص المعروض يبقى كما كتبه SME |
| **المخرجات المهنية بالإنجليزية** | قواعد عرض CV/LinkedIn تنتج إنجليزية (`language_target`) |
| **لا خلط اتجاهات في حقل واحد** | حقل عربي وحقل إنجليزي منفصلان — لا حقل «مختلط» |
| **نص بلا مقابل في اللغة الأخرى** | يُوسَم `translation_pending` ويظهر في بوابة G-18 — **لا يُنشر** |

## 8. تقارير تشغيل الخط *(كلها قابلة للأتمتة مبكرًا)*

| التقرير | يرصد |
|---|---|
| Unmapped Report | صيغ لم تُطابَق بعد |
| Near-Duplicate Report | مهارات متقاربة بلا علاقة مسجّلة |
| Coverage Report | مهارة أساسية بلا نشاط · فجوة بلا مورد · بند بلا مهارة · نشاط بلا فحص نزاهة |
| Staleness Report | مورد لم يُفحص منذ مدة · إشارة سوق منتهية · مصدر تغيّر إصداره |
| Review Queue | ما ينتظر SME وزمن الانتظار |
| Provenance Gaps | سجل بلا مصدر أو بلا مراجع |
| Bilingual Gaps | حقول `translation_pending` |

---

## 9. ما لا يفعله الخط
1. **لا ينشر شيئًا بلا اعتماد SME.**
2. **لا يعدّل حقيقة الدور من إشارات السوق.**
3. **لا يدمج مهارتين آليًا.**
4. **لا يخمّن مطابقة غامضة.**
5. **لا يستخرج من مصدر بما يخالف ترخيصه.**
6. **لا يحذف شيئًا** — الإهمال حالة (`deprecated`/`retired`) لا حذف.
