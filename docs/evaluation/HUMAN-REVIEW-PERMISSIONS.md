# Human Reviewer Permissions — وSME دورٌ آخر
**المبدأ:** المراجع/ة البشري/ة يراجع **تسليمات** مقابل رُبريك **معتمد سلفًا**. الـSME يراجع/يعتمد **محتوى المهن** (دور · مهارات · مهام · أنشطة · رُبريكات). قد يكونان شخصًا واحدًا مؤقتًا في Phase 0، و`role_performed` يُخزَّن **صراحةً** في كل منحة وقرار وسجل مراجعة. لا يُدمَجان مفهوميًا.

## المنحة
`reviewer_grant (user_id, role_performed, granted_by, granted_at, revoked_at)` — فعل مشغّل، لا خدمة ذاتية. `HumanReviewerGuard` يقبل `human_reviewer` فقط. منحة `sme` لا تفتح قائمة المراجعة.

## يجوز للمراجع/ة (`REVIEWER_MAY`)
| الفعل | الآلية |
|---|---|
| تحديد نتيجة بند | `POST /review/items/:id/decision` — مستوى من مستويات البند |
| كتابة المبرّر | إلزامي ≥ ١٢ حرفًا (قيد قاعدة + نطاق) |
| تأكيد/تجاوز الحكم **على بنود الحكم** | `disagreement_with_automated_result` يُسجَّل |
| طلب إعادة مراجعة | قرار جديد بـ`supersedesReviewId` |
| إرجاع البند / تصعيده | `return` · `escalate` بسبب مكتوب |

## لا يجوز (`REVIEWER_MAY_NOT`) — وكيف يُمنع
| الفعل | المنع |
|---|---|
| اختلاق دليل | لا مسار كتابة على `evidence`؛ RLS يرفض الإدراج (مُختبَر) |
| تعديل التسليم | لا مسار API؛ RLS: `update submission/submission_artifact` ⇒ صفر صفوف (مُختبَر) |
| تعديل ملف المستخدم | لا مسار API؛ RLS |
| نشر ادعاء CV/LinkedIn | لا مسار؛ مسار الاعتماد للمستخدم وحده (D-057) |
| تغيير متطلبات الدور / تعريف الرُبريك | لا مسار؛ الرُبريك المنشور مجمّد (مُحفِّز) |
| تجاوز فشل حتمي | بند `rule` ⇒ لا صف قائمة أصلًا؛ قرار عليه مرفوض (`validateDecision`)؛ فشل نزاهة حاجب ⇒ لا قائمة |
| تعديل حالة الدليل مباشرة | RLS صفر صفوف (مُختبَر)؛ الانتقال يملكه النطاق |
| منح `Verified` | `rubric_never_proposes_verified` + `transition_verified_not_yet_available` + `assertStateAvailableInProduction` (D-059) |

**`human_override_up` (قواعد السلّم V1–V8):** لم تُمَس. المراجع/ة يقرّر بنودًا؛ **الحالة** يقرّرها النطاق من التجميع، ولا يوجد مدخل لرفع حالة يدويًا.

## تعارض المصالح
صاحب التسليم لا يراجعه: الإسناد يُرفض `403` **ويُصعَّد البند** بعلَم `conflict_of_interest` (يبقى بعد الرفض — معاملة مستقلة). تصريح المراجع بتعارض ⇒ نفس المسار. يُسجَّل على كل قرار.
