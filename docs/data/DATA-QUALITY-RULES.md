# قواعد جودة بيانات المهن — `npm run career:validate`
كل قاعدة تُعيد الصفوف المخالفة. قاعدة `fail` بمخالفة ⇒ كود خروج 1. **تفشل بصوت مسموع.** الكود: `apps/api/src/career-data/quality-rules.ts`.

| # | القاعدة | الشدّة | ما تفحصه |
|---|---|---|---|
| Q01 | مهارات كانونية مكرّرة | fail | تطابق مفتاح المطابقة المُطبَّع (عربي أو إنجليزي) بين مهارتين `active` — `isExactDuplicate` |
| Q02 | مراجع ربط دور↔مهارة معطوبة | fail | ربط إلى مهارة `deprecated`/`merged_into` |
| Q03 | مهارة بلا مصدر | fail | لا `source_ref` |
| Q04 | نشاط بلا رُبريك | fail | ولا رُبريك منشور لنشاط منشور |
| Q05 | بند **دليل** بلا مهارة مرتبطة · بند **بوابة/جودة** مربوط بمهارة | fail | `criterion_kind` (OPEN-044) + رُبريك منشور بلا بنود ولا لقطة |
| Q06 | مهارة أساسية بلا مسار دليل | fail | `is_core` ولا نشاط يقيسها ببند مرتبط — `evidencePathStatus = none` |
| Q07 | محتوى منشور بلا اعتماد SME | fail | `published` و`is_demo_fixture = false` و`reviewed_by` فارغ |
| Q07b | محتوى DEMO منشور | **warn** | مسموح خارج الإنتاج فقط؛ الـAPI يرفض الإقلاع به في الإنتاج |
| Q08 | مورد تعلّم بلا رابط تطبيق أو >٣ لمهارة | fail | `practice_activity_spec_id` فارغ · عدّ لكل مهارة |
| Q09 | نشاط قابل لـVerified بلا مسار تحقق معتمد | fail | أي `can_yield_verified = true` (لا سياسة تحقق في Phase 1) |
| Q10 | دمج مترادفات غير صالح | fail | هدف دمج غير active · broader/narrower متبادل · صيغة `equivalent` تساوي اسمًا كانونيًا لمهارة أخرى **فعّالة** (اسم مرادف مدموج ليس كانونيًا) |
| Q11 | إسناد مفقود | fail | سجل بلا `source_ref` في ١٣ جدولًا · مرجع إلى مصدر غائب · **إسناد معلَّق** لكيان لم يعد موجودًا |
| Q12 | AI-assisted معتمد/منشور بلا مراجع | fail | `drafting_aid = ai_assisted` بلا `reviewed_by` |
| Q13 | إشارات سوق مستوردة | fail | مصدر سوق فوق `curated` · لقطة من مصدر سوق · أي `market_fact` · أي `demand_ratio` |
| Q14 | اكتمال ثنائي اللغة | fail | أسماء/عناوين فارغة في أي من اللغتين |
| Q15 | اكتمال سجل المهارة | fail | عائلة · نوع · قابلية الإحلال · سياسة حداثة · مقياس · مؤشرات |
| Q16 | تغطية قواعد العرض | fail | كل `asset_type × {practiced, demonstrated, verified}` |
| Q17 | فحص نزاهة بلا نوع | warn | صفوف قديمة |
| Q18 | مهارة في ربط الدور لا يقيسها نشاط ولا مهمة | warn | *(كانت تظهر `ui-testing` في المسار الجديد حتى 0.2.0؛ أُزيلت بـOD-3)* |
| Q19 | سجل كانوني يشير إلى سجل DEMO | fail | ربط/بند/مورد غير تجريبي يشير إلى مهارة أو مهمة أو نشاط `is_demo_fixture = true` (بعد الترقية يجب أن تُحلّ المراجع إلى النسخ الكانونية — D-096) |
| Q20 | رُبريك غير تجريبي منشور بقيمة غير معتمدة | fail | `published` و`is_demo_fixture = false` وأي `weight_status`/`threshold_status`/`pass_threshold_status` ≠ `approved` (OPEN-043 · D-095) |
| Q21 | بند بشري لا يمكن مراجعته | fail | `evaluator_type ∈ {human, llm}` بلا صفوف `rubric_criterion_level` — المراجع لا يجد واصفات يحكم بها |
| Q22 | فحص نزاهة حتمي نشط يعتمد على أداة لا مُنتِج لها (OPEN-045) | fail | `evaluation_mode = deterministic` و`active` ومفتاح أداة خارج سجل المُنتِجين (`file.*` · `note.*` · `answer.*` · `test.*`) |
| Q23 | بند اكتمال قد يُنتج دليل مهارة (OPEN-044) | fail | بُعد `completeness` أو مكتبة `core.completeness.deliverables` مع `criterion_kind = skill_evidence` |
| Q24 | قيمة `approved` بلا فعل اعتماد مُسجَّل (OPEN-043) | fail | وزن/عتبة/عتبة اجتياز `approved` و`rubric_version.values_approved_at` فارغ |

**النتيجة على قاعدة نظيفة بعد الاستيراد (بعد Q22–Q24):** ٢٢ PASS · ٠ FAIL · ٢ WARN (Q07b محتوى الشريحة ١ التجريبي منشور · Q18 `skl_ui_state_interaction` في دور الشريحة ١ — نتيجة إعادة توجيه الربط من المرادف؛ `ui-testing` لم تعد في دور الحزمة منذ 0.2.1). **Q01 تتجاهل زوج (أصل DEMO · نسخته الكانونية)** لأن تعايشهما بالمفتاح نفسه مقصود أثناء الترقية. **ما كشفته أثناء البناء:** الدور التجريبي في الشريحة ١ كان يعلّم `ui-state-management` أساسية بلا أي نشاط يقيسها (Q06) — صُحِّح في البذرة إلى `is_core = false`؛ وإعادة الاستيراد كانت تترك إسنادًا معلَّقًا لبنود الرُبريك المُعاد إنشاؤها (Q11 المُوسَّعة) — صُحِّح في الخط.

**ملاحظة:** الأداة مخصّصة لقواعد المحتوى. قاعدة اختبار بعد تشغيل e2e تحمل صفوفًا اختبارية عمدًا (دور demo منشور بمتطلبات بلا مسار دليل) فتفشل Q06/Q11 — وهذا سلوك صحيح للأداة لا عيب فيها.
