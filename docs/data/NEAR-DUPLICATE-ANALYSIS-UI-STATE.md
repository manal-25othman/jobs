# OPEN-039 — تحليل التكرار: `ui-state-management` مقابل `skl_ui_state_interaction`
> **قرار المالكة (2026-09-27 · D-097):** قُبلت التوصية `equivalent`. الكانونية `skl_ui_state_interaction`؛ `ui-state-management` مرادف يحتفظ بمعرّفه وتاريخه (`merged_into`، لا حذف). مُطبَّق في الحزمة 0.2.0 ومُختبَر. **OPEN-039 مُغلق.** ما يلي هو التحليل الذي سبق القرار.

**لا دمج آلي. القرار للمالكة/SME.** تشابه مفتاح المطابقة العربي 0.9 (تقرير التكرار).

| البُعد | `ui-state-management` (الشريحة ١) | `skl_ui_state_interaction` (الحزمة) |
|---|---|---|
| المعنى الكانوني | «إدارة حالة الواجهة» — تسمية تجريبية بلا تعريف مكتوب (وصف عام «demo fixture») | «تمثيل حالة الواجهة صراحةً وربط التفاعلات بتحوّلات حالة متوقعة» |
| النطاق | غير محدّد؛ يُوحي بالحالة وحدها | الحالة **والتفاعل** (الأحداث ← تحوّلات ← عرض) |
| المؤشرات الملاحَظة | placeholder («يكتبه مؤلف المحتوى») | ٣ مؤشرات: تمثيل واحد لكل حالة · التفاعل يغيّر الحالة ثم العرض · لا تناقض بين المعروض والمحفوظ |
| الدليل المتوقَّع | `artifact` · `decision_rationale` | `artifact` · `decision_rationale` · `live_defense` |
| أنماط الفشل | — | حالة في DOM · حالتان متناقضتان · تحميل لا ينتهي |
| المصدر | بذرة الشريحة ١ (`src_naqla_demo_fixture`) | حزمة v0.1 (`src_naqla_frontend_pack_v0_1`) |
| الاستخدام الحالي | ربط الدور التجريبي (غير أساسية بعد Q06) · لا نشاط يقيسها · **بيانات مستخدمين اختبارية تشير إليها (ادعاءات)** | ٥ أساسية في المسار الجديد · نشاطان · ٢ بند رُبريك |

## الاحتمالات
| العلاقة | التقدير | لماذا |
|---|---|---|
| `equivalent` | **مرجّح دلاليًا** | المفهوم واحد؛ الفرق تسمية وتفصيل |
| `broader` (الأولى أوسع) | ضعيف | «إدارة الحالة» قد تشمل حالة التطبيق عبر مكتبات — لكن الشريحة ١ لم تعرّفها كذلك |
| `narrower` | لا | — |
| `related` (الحالي) | مقبول مؤقتًا | لا يفقد شيئًا ولا يقرّر شيئًا |
| `keep_separate` | مكلف | يقسم أدلة المستخدم بين معرّفَين فلا تبلغ أيٌّ منهما `Verified` (الخطر الخفي، وثيقة 24 §5) |

## أثر كل خيار
- **دمج (`ui-state-management` → `merged_into` → `skl_ui_state_interaction`):** المهارة القديمة تبقى بمعرّفها (لا حذف)، الأدلة القديمة تُحلّ عبر `merged_into_id`؛ الربط التجريبي يُحدَّث بقرار. **لا يُطبَّق إلا بموافقة المالكة الصريحة** — والدمج غير قابل للعكس عمليًا.
- **إبقاء منفصلتين:** انقسام الأدلة، وتشويش في العرض («إدارة حالة الواجهة» و«إدارة حالة الواجهة والتفاعل» معًا).
- **`related` (كما هو):** آمن مؤقتًا؛ يؤجّل القرار.

## التوصية
`equivalent` عند اعتماد الحزمة: تُعلَن `skl_ui_state_interaction` الكانونية (تعريف ومؤشرات كاملة)، وتُسجَّل `ui-state-management` مترادفًا `equivalent` بصيغة «إدارة حالة الواجهة»، ثم تُدمج بـ`merged_into` **بعد** الموافقة. حتى ذلك: `related` يبقى، و`dedup_candidate.decision = proposed`.
