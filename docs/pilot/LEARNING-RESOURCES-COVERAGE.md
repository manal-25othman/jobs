## 4. الربط بمحتوى خارجي مقابل نسخه أو إعادة توزيعه

**ما تفعله المنصة الآن: ربط فقط.**
- السجل يحفظ **بيانات وصفية**: العنوان كإسناد، والمزوّد، والرابط، ونوع المورد، ولغته.
- يحفظ أيضًا **سبب ترشيح كتبناه نحن بالعربية**.
- الخرّيج يضغط الرابط فيُفتح موقع المزوّد في نافذة جديدة (`rel="noopener noreferrer"`).
- لا تنسخ المنصة نصًا ولا صورًا ولا كودًا من المورد، ولا تخزّنه، ولا تترجمه، ولا تضمّنه، ولا تعيد نشره.

**ما يقوله الترخيص المسجَّل:** التراخيص التي قرأتها جلسة الفحص تحكم **إعادة الاستخدام والتوزيع والتعديل**، لا الربط المجرد.

|---|---|
| MDN | CC-BY-SA 2.5 أو أحدث. الصفحة تقول صراحة «yes, you can link to MDN Web Docs!» |
| web.dev وChrome وGoogle للمطوّرين | CC BY 4.0، والكود Apache 2.0 |
| WHATWG | CC BY 4.0 |
| W3C | رخصة W3C للمستندات |
| git-scm | CC BY-NC-SA |

**متى يتغيّر الحكم؟** إن أرادت المنصة لاحقًا:
- اقتباس محتوى من المورد؛
- تضمينه في الصفحة؛
- ترجمته؛
- أو تحويله إلى درس داخلي.

عندها تنطبق شروط الترخيص:
- **الإسناد** في كل التراخيص أعلاه؛
- **المشاركة بالمثل** في CC-BY-SA وCC BY-NC-SA؛
- **منع الاستخدام التجاري** في CC BY-NC-SA (git-scm): لا يجوز إدراج محتواه في عرض تجاري.

هذا قرار ترخيص يتوقف عنده العمل لموافقة مالكة المنتج قبل أي تنفيذ. لا شيء منه منفَّذ الآن.
