# @naqla/ui

Empty in Phase 0, on purpose.

The design tokens and components are in the frozen prototype at
`apps/web/assets/css/`. They move here — moved, not copied — when the screens
are rebuilt in Next.js. Until then there is one source of truth for every token
value, and it is the frozen prototype.

This package will decide how things look. It will never decide whether
something is true: that lives in `@naqla/domain`.
